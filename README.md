# Hi, I'm Lucas Porto

### Senior QA Engineer | Test Automation | Performance Testing | Quality Engineering

I’m a Senior QA Engineer experienced in building quality strategies across the software development lifecycle. My background includes test automation, exploratory and manual testing, API testing, mobile automation, performance testing, security testing, and CI/CD integration.

I focus on creating reliable and maintainable testing solutions that help teams identify risks earlier, release with confidence, and continuously improve software quality.

## What I Do

- **Test Automation:** Design and maintain scalable automation frameworks for web, API, and mobile applications using Playwright, Cypress, Selenium, CodeceptJS, Supertest, Appium, Mocha, and Cucumber.
- **Quality Strategy:** Define testing approaches across different layers of the application, combining automated, exploratory, integration, regression, and end-to-end testing.
- **Performance Testing:** Plan and execute load and performance tests with JMeter and Locust, analyzing scalability, stability, response times, and system behavior under stress.
- **CI/CD Integration:** Integrate automated tests and quality checks into GitHub Actions and GitLab CI/CD pipelines to provide fast and reliable feedback.
- **Security and Accessibility:** Perform security testing with OWASP ZAP and accessibility and performance audits with Lighthouse.
- **Observability and Debugging:** Investigate application behavior using Datadog, Grafana, AppDynamics, Sentry, Kibana, and Splunk.
- **Data Validation:** Validate application data and integrations across SQL Server, PostgreSQL, DynamoDB, Firebase, and other distributed systems.
- **Agile Collaboration:** Work closely with engineers, product managers, designers, and other stakeholders in Scrum and Kanban environments.

## How I Approach Quality

I advocate for a shift-left approach in which quality is considered from the earliest stages of product development. I believe effective quality engineering goes beyond finding defects: it involves preventing issues, improving feedback loops, increasing observability, and helping teams make informed decisions about risk.

I also value collaboration and knowledge sharing. Throughout my career, I have contributed to onboarding QA engineers, sharing testing practices, and helping teams improve their quality processes and automation strategies.
